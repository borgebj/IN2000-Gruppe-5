# IN2000-Gruppe-5
Gruppe 5 for IN2000 prosjektet

Dette er prosjektfilene for gruppe 5 i IN2000.

Prosjektet vårt går ut på Case 6. Åpent case - Hvor vi har vært enige om å velge punkt 2. Luftkvalitet.
Vi skal altså lage en god og brukervennlig app som fremviser Luftkvalitet i Oslo og andre storbyer i Norge.
